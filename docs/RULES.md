# Правила игры

Логическая головоломка в жанре «загадки Эйнштейна». Предметы — эмодзи, подсказки — отношения между ними.

## Поле

- Поле — это **N строк × N столбцов**. Каждая строка — категория предметов одной темы.
- Скрытое решение: в каждой строке каждый из N предметов стоит ровно в одном столбце.
- В начале в каждой клетке видны все N кандидатов строки. Цель — оставить в каждой клетке ровно один, правильный.
- Часть клеток может быть открыта заранее.

Наборы символов задаются в `src/app/game/symbols.ts`. Одна строка — буквенная: слово из неповторяющихся букв (`CASE`, `BAKER`, `HOLMES`, `SHERLOCK` — по размеру поля). Буквы рисуются плитками, а не эмодзи: эмодзи-буквы рядом склеиваются во флаги.

Примеры категорий (подбираются так, чтобы эмодзи хорошо различались):

| Тема      | Предметы          |
|-----------|-------------------|
| Цвета     | 🟥 🟧 🟨 🟩 🟦 🟪   |
| Еда       | 🍎 🍋 🍇 🥒 🥕 🍆   |
| Животные  | 🐱 🐶 🐸 🐰 🦊 🐼   |
| Постройки | 🏠 🏰 ⛺ 🏭 ⛪ 🗼   |
| Транспорт | 🚗 🚲 🚀 ⛵ 🚂 🛸   |
| Хобби     | ⚽ 🎸 🎲 🎨 📚 🎮   |

## Управление

- **Тап / ЛКМ по кандидату** — исключить его. Повторный тап возвращает.
- **Долгое нажатие / ПКМ** — выбрать кандидата как ответ для клетки.
- Выбранный ответ автоматически исключается из остальных клеток строки. Если в клетке остался один кандидат или кандидат остался только в одной клетке строки, он выбирается сам. Автоматику можно отключить.
- **Отмена / повтор** — без ограничений по числу шагов.
- **Тап по подсказке** — пометить её «использованной» (она тускнеет). Повторный тап снимает пометку.

## Подсказки

«Справа» означает столбец с большим номером. Ниже `A`, `B`, `C` — любые предметы, в том числе из разных строк.

### Вертикальные (про один столбец)

| Запись           | Значение                         |
|------------------|----------------------------------|
| `A` над `B`      | A и B в одном столбце            |
| `A` над `B` с ✕  | A и B в разных столбцах          |

### Горизонтальные (про порядок столбцов)

Общее правило записи: **без стрелки — рядом, со стрелкой — где-то дальше**.

| Запись        | Значение                                                       |
|---------------|----------------------------------------------------------------|
| `A B`         | B сразу справа от A                                            |
| `A → B`       | B где-то правее A (на любом расстоянии)                        |
| `A ↔ B`       | A и B в соседних столбцах, порядок не важен                    |
| `A ↮ B`       | A и B **не** в соседних столбцах (в одном столбце — можно)     |
| `A B C`       | три соседних столбца ровно в этом порядке                      |
| `A → B → C`   | A левее B, B левее C, не обязательно рядом                     |
| `A ✕B C`      | B не стоит между A и C (A и C — в любом порядке)               |

## Уровни сложности

| Уровень | Поле | Открытые клетки | Лишние подсказки | Нужные приёмы                                                  |
|---------|------|-----------------|------------------|----------------------------------------------------------------|
| 1       | 4×4  | 2               | 2                | одиночки в строке и прямое следствие одной подсказки           |
| 2       | 5×5  | 1               | 1                | то же, больше типов подсказок                                  |
| 3       | 6×6  | —               | 1                | + группы в строке: k клеток, где возможны только k предметов   |
| 4       | 6×6  | —               | —                | + совместное следствие двух подсказок с общим предметом        |
| 5       | 8×8  | —               | —                | + рассуждение «от противного»: предположение быстро ломается   |

Без лишних подсказок каждая подсказка нужна: если её убрать, логикой уровня головоломку уже не решить.

## Гарантии генератора

1. У головоломки ровно одно решение.
2. Она решается логикой, без угадывания. Генератор проверяет это собственным решателем, который ходит только «честными» шагами.
3. Сложность оценивается по тому, какие приёмы нужны решателю, а не только по размеру поля.
4. На уровне 5 генерация занимает несколько секунд, поэтому следующая головоломка готовится заранее в фоне.

## Помощь и ошибки

- Ошибки сразу **не** подсвечиваются: можно исключить правильный кандидат и не узнать об этом.
- Кнопка «подсказать шаг»:
  - если на поле есть ошибка, показывает её;
  - иначе подсвечивает подсказку и кандидатов, которых она позволяет исключить прямо сейчас.
- Каждая помощь записывается в статистику партии.

## Сохранение

Всё хранится в `localStorage` браузера:

- текущая партия: поле, история ходов, таймер, пометки подсказок;
- настройки: язык, автоматика;
- статистика по уровням: сколько решено, лучшее время, сколько раз брали помощь.

## Интерфейс

- Минималистичный, тёмный, без надписей: иконки и эмодзи. Текст есть только на экране правил (RU/EN).
- Таймер ставится на паузу, когда вкладка скрыта; во время паузы поле прячется.
- Раскладка рассчитана и на компьютер (подсказки справа от поля), и на телефон (подсказки под полем).
